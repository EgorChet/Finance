# Ч-Банк · brand book

The app is called **Ч-Банк**. One mark, four colour palettes (each in a dark and a light theme), all driven
by CSS variables in `web/src/assets/theme.css`. Nothing in the app should hard-code a brand colour.

## Logo

**Letter construction (one system for all five letters):** cap height 32, stroke 6, round caps and round joins,
outer width 26 for every letter, drawn with paths (no font). Optical kerning: diagonals (А) sit 4 units closer,
straight-to-straight pairs have a gap of 7. The Ч inside the square has *exactly* the cap height and stroke of the
letters in the word and sits on the same top and bottom lines, so it never looks smaller or from another font.
Square 60×60, corner radius 17; the word is vertically centred on the square (cap lines 14 and 46).
The Ч glyph: `M3 3V14Q3 19 8 19H23` + `M23 3V29`. БАНК: Б `M23 3H3V29H14Q23 29 23 23.5Q23 18 14 18H3`,
А `M3 29L13 3L23 29M6.2 21H19.8`, Н `M3 3V29M23 3V29M3 16H23`, К `M3 3V29M23 3L3 17M9.5 12.5L23 29`.


- Letters are drawn with paths, not a font, so the logo looks the same on every device.
- Colours: the square uses `--accent-fill`, the Ч uses `--accent-contrast`, the word uses the text colour.
- Minimum size: mark 24 px, lockup 120 px wide. Clear space around it: one quarter of the mark's width.
- Component: `web/src/shared/components/AppLogo.vue` (`animated` plays the draw-on, `lockup` adds БАНК).
  The launch screen in `web/index.html` has an inline copy; icons are generated by `web/scripts/make-icons.mjs`.
  The home-screen icon and favicon are always the gold mark.

## Palettes

The user picks a palette in the account menu; the theme (dark / light) is a separate switch. Both are
remembered on the device (`finance_palette`, `finance_theme`) and applied before the first paint
by a small script in `index.html`.

## Tokens

| Token | Use |
|---|---|
| `--accent` | Brand colour as **text, icons, links, outlines** (readable on the background) |
| `--accent-fill` / `--accent-fill-strong` | Brand colour as a **surface**: buttons, toggles, progress and bar fills, active pills |
| `--accent-contrast` | Text or icon **on** a fill (ink on gold and emerald, white on cobalt and carmine) |
| `--accent-gradient` | Buttons and avatars |
| `--accent-2` | Secondary tint of the same hue |
| `--glow-1..3` | Soft background light |
| `--bg`, `--surface`, `--surface-alt`, `--surface-raised`, `--border`, `--text`, `--text-muted`, `--text-faint` | Neutrals |

Rules:
1. Never use `--accent` as a background or `--accent-fill` as text colour: on the light theme gold text would be unreadable.
2. Text on a brand-coloured surface always uses `--accent-contrast`, never `#fff`.
3. **Status colours do not follow the palette.** Plus/good is green (`--success`), warning amber (`--warning`),
   minus/bad red (`--danger`). A "+" or "−" sign always accompanies them, so Emerald and Carmine stay unambiguous.
4. Category and chart series colours are their own set and stay the same in every palette.

## Components (all use the tokens above)

- **Primary button**: `--accent-fill`, text `--accent-contrast`; hover `--accent-fill-strong`.
- **Secondary button**: `--surface-alt`, text `--text`. **Outline**: transparent, `--accent` text and border.
  **Destructive**: transparent, `--danger` text.
- **Toggle**: on = `--accent-fill`; **segmented control** and **language switch**: active segment `--accent-fill` or `--surface-alt`.
- **Loaders**: progress and skeleton bars use `--accent-fill`; the launch screen draws the logo in the palette colour.
- **Cards**: `--surface` on `--bg`, 22 px radius, no borders on dark; a soft shadow on light.

## Adding a palette

1. Add its dark and light token sets to the palette block in `theme.css` (`[data-palette="name"]` and
   `[data-palette="name"][data-theme="light"]`; the light block must set every token).
2. Add the name to `PALETTES` in `web/src/shared/stores/app.ts`, to the regexp in the script in `index.html`,
   to its launch-screen colours in `index.html`, and to `PALETTE_OPTIONS` (with a Russian name) in `AppShell.vue`.
3. Check both themes at 440 px: buttons, toggles, tabs, bars, the launch screen.
